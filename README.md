# 象罔社 · 新人练习仓库

这是象罔社 2026 秋季招新的练习仓库。**八周里你写的代码都放在这里**，每周提一个 PR。

## 第一次用：W1 要做的三件事

1. **Fork**：点右上角 `Fork`，把仓库复制一份到你自己的账号下。
2. **新建你的文件夹**：在你的 Fork 里进入 `students/`，新建文件夹，名字用：

   ```
   26级-专业-姓名
   ```

   例如 `26级-计算机-张三`。里面放一个 `README.md`，写三行：姓名、专业、选的赛道（开发 / 科研），再加一句你为什么来。
   （格式照着 `students/示例-26级-计算机-张三/README.md` 抄，记得改名字。）

3. **提 PR**：提交后回到这个仓库，点 `Contribute` → `Open pull request`，标题写「W1-26级-专业-姓名」。

## 规矩

- **一人一个文件夹，不要改别人的文件。**
- **不要提交密钥。** API key、密码、token 一律不进仓库。
- **不要提交虚拟环境和缓存**：`.venv/`、`venv/`、`__pycache__/` 已经在 `.gitignore` 里，别强推。
- **不要传大文件**（视频、模型、数据集）。视频交到群作业，不往这里放。
- 一个 PR 只做一件事。提完等社长合并就行，合不合并不影响你的分。
